# Мой ТВ — лаунчер для Android TV

Главный экран в стиле macOS для телевизоров на Android TV / Яндекс ТВ: матовое стекло, большие часы,
погода по местоположению, плитки приложений, док с настройками. Управление только стрелками, ОК и «Назад».

## Установка
1. Скачай `MoyTV.apk` из раздела Releases и поставь на ТВ (через флешку или пульт-приложение).
2. Настройки устройства → Специальные возможности → «Мой ТВ — кнопка «Домой»» → Вкл.

## Сборка (Ubuntu)
```
sudo apt install aapt dalvik-exchange zipalign apksigner android-sdk-platform-23 openjdk-17-jdk
./build.sh
```
Обновления должны быть подписаны тем же ключом `moytv.keystore` (в репозиторий не входит, хранится отдельно).
